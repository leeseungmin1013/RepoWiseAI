# RepoWise AI

RepoWise AI는 GitHub 코드베이스를 분석해 실제 코드 라인을 근거로 인용하면서, 사용자의 이해 수준에 맞춰 문법부터 아키텍처와 수학적 개념까지 단계적으로 설명해주는 개인 맞춤형 AI 코드 학습 가이드입니다.

## 핵심 차별점

- 실제 파일 경로와 라인 번호 기반 코드 citation
- Monaco Editor와 연동되는 citation warp UI
- 파일 트리와 의존성 그래프 기반 코드베이스 탐색
- 사용자 이해도를 문법, 로직, 아키텍처, CS, 수학 층위로 분리 관리
- 코드 설명과 개념 학습을 연결하는 Learning Engine

## 현재 상태

현재 저장소는 프로젝트 기획 및 구현 계획 단계입니다. MVP는 하나의 GitHub 저장소를 분석해 파일 트리, 코드 청크, 하이브리드 검색, citation 기반 AI 답변, 사용자 맞춤형 학습 설명을 제공하는 것을 목표로 합니다.
